What changed vs the slow version Bob is now 0.8s (was 2.2s) and the blink 1.4s (was 2.8s) — roughly 3× faster, so the eye registers it as activity immediately. Every version also adds a second moving element (dots, rings, spinner or bar), because a single looping object reads as decoration while two out-of-sync ones read as work in progress.

For Ramana Bob = AnimationController(duration: 800ms) on repeat/reverse with Curves.easeInOut, offset ±8px. Dots = 3 controllers with 140ms stagger. Rings = scale 0.4→1.45 with opacity 0.6→0, 420ms stagger. Add the caption text (“finding people near you…”) — words remove all doubt that something is loading.

Rule of thumb If a loader runs longer than ~3 seconds, swap it for a skeleton grid (grey placeholder cards). Skeletons feel faster than any spinner because the layout appears instantly.
